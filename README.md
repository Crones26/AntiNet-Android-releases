# AntiNet для Android

[Скачать последнюю версию AntiNet.apk](https://github.com/Crones26/AntiNet-Android-releases/releases/latest/download/AntiNet.apk)

[Все релизы и описание изменений](https://github.com/Crones26/AntiNet-Android-releases/releases)

Это отдельный репозиторий установочных APK мобильной Android-версии AntiNet.

В каждом релизе доступны `AntiNet.apk` и `SHA256.txt`. Сертификат подписи сохранён, поэтому APK предназначен для обновления поверх нашей предыдущей Android-версии с сохранением данных.

При обновлении скачайте APK на телефон и подтвердите установку в системном окне Android. Удалять установленную AntiNet перед обновлением не требуется.
